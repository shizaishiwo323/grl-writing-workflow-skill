# Global Prompt Evaluation Checklist

Use this checklist for every Phase 4 prompt test.

## Routing And Scope

- Did the prompt solve the level it was designed for?
- Did it avoid doing work assigned to another skill?
- If logic was unstable, did it avoid premature sentence polishing?
- Did it state what should not be done yet?
- Did the output make its boundary behavior clear, especially when refusing to do premature lower-level editing?

## Scientific Logic

- Is the central physical process visible?
- Is the mechanism explicit rather than implied?
- Are observations connected to evidence, metrics, and conclusions?
- Are method outputs connected to later claims?

## Reader Experience

- Does the output make the section easier to follow?
- Does it provide topic sentences or reader navigation where needed?
- Does it reduce unnecessary detail?
- Does it preserve target-journal-appropriate movement: concise for GRL, sufficiently developed for full-length AGU Research Articles?

## Narrative Echo And Payoff

Paper-level echo:

- Does the Introduction prepare every major Results concept?
- Does each major Introduction promise receive a payoff in Results/Discussion?
- Are there Introduction claims that never return later?
- Are there Results findings that appear without prior motivation?
- Does the Discussion return to the original gap and broader significance?

Results-level echo:

- Does each Results subsection inherit from the previous one?
- Does each subsection prepare the next analytical step?
- Are forward pointers used before delayed explanation or quantification?
- Are backward links used when a new subsection begins?
- Are thread summaries used to connect multiple findings into one mechanism chain?
- Does the final Results subsection synthesize the previous results rather than introduce an isolated new point?

## Claim Control

- Are claims bounded by evidence?
- Does the prompt avoid adding unsupported mechanisms?
- Does it distinguish representative cases from complete regime maps?

## Output Quality

- Does the output follow the requested format?
- Does it give actionable revision guidance?
- Does it preserve scientific precision?
- Does it avoid generic writing advice?
